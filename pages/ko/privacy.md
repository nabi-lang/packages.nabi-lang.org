# 개인정보 처리방침

> **초안.** 이 문서는 아직 법률 검토를 거치지 않았습니다. 레지스트리를 일반에 공개하기 전에 바뀝니다.

packages.nabi-lang.org가 무엇을 왜, 얼마나 오래 보관하는지 밝힙니다. 패키지는 계정 없이도 볼 수 있으며, 그때는 아무것도 보관하지 않습니다.

## 보관하는 것

- **GitHub 계정 정보**: 로그인할 때 GitHub가 주는 숫자 id, 로그인 이름, 표시 이름, 아바타 주소. 로그인할 때마다 새로 받습니다.
- **세션**: 30일 동안 로그인 상태를 유지하는 쿠키입니다. 로그인에만 쓰며, 추적이나 광고 쿠키는 쓰지 않습니다.
- **공개 토큰**: 해시로만 저장합니다.
- **공개자로서 한 일**: 어떤 버전을 언제 공개하고 yank하고 되돌렸는지, 추가한 소유자와 신뢰 공개자. 각 패키지의 공개 기록이며 패키지 페이지에 보입니다.
- **관리 기록**: 관리자가 계정이나 패키지에 조치한 경우.

## 어디로 가는가

- 페이지와 API는 공개한 것 옆에 로그인 이름, 표시 이름, 아바타를 보여 줍니다.
- 레지스트리는 Cloudflare를 거쳐 운영됩니다. Cloudflare는 트래픽을 전달하고, 쿠키 없이 페이지 조회수를 셉니다(Cloudflare Web Analytics).
- GitHub는 여기에 로그인했다는 사실을 압니다.
- 그 밖의 누구에게도 개인정보를 팔거나 넘기지 않습니다.

## 주소와 로그

서버는 한 클라이언트가 보낼 수 있는 요청 수를 제한하려고 IP 주소를 메모리에만 1분쯤 둡니다. 로그에는 요청 경로와 상태만 남고 주소는 남지 않습니다.

## 보관 기간

계정은 레지스트리가 운영되는 동안, 또는 삭제를 요청할 때까지 보관합니다. 공개 기록은 다른 사람이 의존하므로 패키지와 함께 남습니다. 계정을 삭제하면 그 기록에는 GitHub id와 로그인 이름만 남습니다.

## 권리

보관하는 정보의 열람, 정정, 계정 삭제를 요청할 수 있습니다. security@nabi-lang.org로 연락하십시오.
